## רמזים

- מיון עם שובר שוויון: `sorted(scores.items(), key=lambda pair: (-pair[1], pair[0]))`.
- `evaluate` מצפה ל־`run` כמילון ממזהה שאילתה לרשימת מזהים מדורגת, ול־`labels` כמילון לסטים.
- אם `compare_retrievers` נכשל על מכסה (429), הלקוח מפרק 11 כבר מנסה שוב; אם המכסה היומית נגמרה,
  הריצי מחר. הכותרות במטמון, אז רק 20 שיכונים ו־20 קריאות דירוג חוזרים.
