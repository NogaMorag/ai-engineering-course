# תרגיל פרק 5: ספירת טוקנים ובדיקת „איפה המידע חי”

**מטרה:** למדוד כמה טוקנים עולים שישה סוגי טקסט, ובפרט עברית מול אנגלית; ואז לבדוק בשלוש שאלות
איפה המידע של המודל נמצא: במשקולות, בהקשר, או בשום מקום.

**זמן משוער:** שני ימי לימוד (ימים 7 ו־8), כ־45 דקות בנייה בכל אחד. **ידע מקדים:** פרק 5, ומפתח API
פעיל מפרק 2. ספירת הטוקנים אינה מייצרת טקסט ולכן אינה עולה כסף גם במסלול בתשלום; בדיקות המידע הן
שלוש קריאות קטנות.

## מה בתיקייה הזאת

| קובץ | תפקיד |
| --- | --- |
| `starter/token_counting.py` | שישה טקסטים ושני `TODO`: היחס תווים לטוקן, וקריאת הספירה |
| `starter/knowledge_probe.py` | שלוש בדיקות ו־`TODO` אחד: הקריאה למודל |
| `solution/` | שני הפתרונות המלאים |
| `tests/test_ch05.py` | ארבע בדיקות שרצות בלי רשת |

הקצה של ספירת הטוקנים, והתוצאה בשדה `total_tokens`.

## רמזים

1. `response.total_tokens` יכול להיות ריק (`None`) במקרים חריגים; החזירי אפס במקום.
2. אם קיבלת שגיאת 429: המסלול החינמי מגביל בקשות לדקה. חכי דקה והריצי שוב; שישה טקסטים ושלוש
   בדיקות הם תשע קריאות בלבד.
3. אם העברית בטבלה מודפסת כסימני שאלה, חזרי לסעיף 2.2 בפרק 2 (משתנה הסביבה) ופתחי טרמינל חדש.

## הפתרון

הקבצים בתיקייה `solution/` מכילים את המימוש המלא. **מה הפתרון מדגים:** ספירת טוקנים עם הכלי של
המודל במקום ניחוש; הפרדת החישוב הטהור (היחס, העיצוב) מהקריאה לרשת; ושלושת המקומות שבהם מידע חי,
במו עינייך.
