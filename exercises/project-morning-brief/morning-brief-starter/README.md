# Morning Brief: starter

This is the course starter: the full project structure, tests, fixtures, docs, workflows and prompts,
with every function body replaced by `raise NotImplementedError`. Chapter 31 walks through the nine milestones;
each milestone names the modules to implement and the tests that must pass. The reference implementation
lives next to this directory (`../morning-brief`) for when you are stuck.

<div dir="ltr" align="left">

```powershell
uv sync
uv run pytest -q           # red at first; green by the end of M9
uv run morning-brief run --offline
```
