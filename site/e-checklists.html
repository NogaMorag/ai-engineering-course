נספח ה: רשימות בדיקה: למידה ומוכנות לראיון

שתי רשימות. הראשונה בודקת שלמדת: לכל חלק, מה את יכולה להסביר ומה את יכולה להראות. השנייה בודקת שאת מוכנה לראיון: מה מוכן, מה תורגל, מה כתוב. מסמנים ביום 79, ואז בכל חודש של חיפוש.

כל פריט הוא כן או לא, עם ראיה: קובץ שקיים, בדיקה שרצה, או מספר עם מכנה. „הסברתי בקול” נחשב רק אם עשית את זה עכשיו, עם שעון, בלי לפתוח את הספר. פריט שאין לו ראיה כזאת לא מסומן.

רשימת למידה

חלק א: יסודות וסביבה (פרקים 0 עד 2)

  • [ ] הסברתי בקול, בשתי דקות, מה מהנדסת AI בונה ולמה „הקוד מחליט, המודל מציע”, עם דוגמה מהפרויקט.
  • [ ] שתי פקודות מדפיסות גרסאות בטרמינל: uv --version, ו־uv run python --version מראה 3.12.
  • [ ] קובץ הסודות מוחרג: .env רשום ב־.gitignore, והוא לא מופיע בפלט של git status.
  • [ ] עברית מודפסת נכון בטרמינל (ב־Windows: אחרי הגדרת PYTHONUTF8 וטרמינל חדש).
  • [ ] הקריאה הראשונה (פרק 2) רצה והדפיסה מספר טוקנים ועלות משוערת; המספרים רשומים ביומן של יום 2.
