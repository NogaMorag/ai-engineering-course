# למידת מכונה בפרק אחד

- **מודל:** פונקציה שהמבנה שלה אנושי והמספרים שבה נלמדו מדוגמאות.
- **שלוש למידות:** בפיקוח (תוויות), ללא פיקוח (מבנה), בפיקוח עצמי (היעד מהנתונים; כך מודל שפה).
- **הכללה:** המספר היחיד שחשוב נמדד על דוגמאות שהמודל לא ראה. 1.00 מול 0.60 הוא שינון.
- **חלוקה:** אימון, בחירה, בדיקה. פעם אחת, לפני הכול. ניסוחים של אותו מקרה באותו צד.
- **זליגה:** מה המערכת יודעת ברגע ההחלטה? אם התשובה „את התשובה”, זו זליגה.
- **מדידה:** מטריצת בלבול; Precision מול Recall; מחיר הטעות מחליט; הסף מזיז; מונה ומכנה תמיד.
- **קודם בסיס:** „תמיד לא” נותן 0.92. מה המודל שלי קונה מעבר לזה?
- **שאלה פתוחה:** ___

<div dir="ltr" align="left">

```text
accuracy  = (TP + TN) / all          precision = TP / (TP + FP)
recall    = TP / (TP + FN)           f1        = 2 * P * R / (P + R)
example   TP=6 FP=4 FN=2 TN=88  ->  acc 0.94  precision 0.60  recall 0.75  f1 0.67
baseline  "never urgent"        ->  acc 0.92  recall 0.00
toy model train 1.00 / held-out 0.60  (overfitting)   with leaked fields: 1.00 (lie)
```
